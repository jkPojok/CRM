CRM Learn — это бэкенд-приложение, разработанное для отработки навыков создания REST API на Python. Проект имитирует реальную медицинскую CRM-систему: управление врачами, пациентами и записями на прием.

Технологический стек
Язык: Python 3.x
Фреймворк: Django, Django REST Framework (DRF)
База данных: SQLite (для локальной разработки)
Архитектура: REST API, паттерн MVC (Model-View-Controller)
