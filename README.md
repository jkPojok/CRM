CRM Learn — это бэкенд-приложение, разработанное для отработки навыков создания REST API на Python. Проект имитирует реальную медицинскую CRM-систему: управление врачами, пациентами и записями на прием.

Технологический стек
Язык: Python 3.15
Фреймворк: Django, Django REST Framework (DRF)
База данных: SQLite

Планы по развитию (Roadmap)
* Добавить бизнес-логику (сейчас только базовый CRUD с API).
* Добавить JWT-авторизацию и разграничение прав доступа (Врач, Пациент, Бухгалтер/Аналитик, Админ и другие).
* Подключить Pydantic.
* Контейнеризация проекта (Docker, Docker Compose) с переходом на PostgreSQL.
